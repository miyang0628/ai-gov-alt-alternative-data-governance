# AI-Gov-Alt — Experiments

Reproducible experiments for a Design Science study of a **real-time governance
framework for alternative-data credit scoring and insurance underwriting**.

> Anonymized for double-blind review. Author and affiliation withheld.

The experiments test one central claim: **removing a protected attribute alone
does not remove discrimination**, because correlated proxy variables retain the
group signal — and a governance **fairness engine** (group-wise threshold
calibration) can restore parity while preserving predictive utility, subject to
a legal admissibility precondition.

---

## Results at a glance

All metrics are means over 30 random seeds (10 per cell for E4) with 95% CIs.
DIR = Disparate Impact Ratio (1.0 = parity; 0.8 = "four-fifths" threshold).

**E1 — Synthetic demonstration**

| Condition | AUC | DIR |
|---|---|---|
| with_protected | 0.992 | 0.298 |
| drop_protected_only | 0.992 | 0.299 |
| drop_proxies_too | 0.718 | 0.986 |
| **gov_engine** | **0.992** | **1.000** |

**E2 — Real benchmark (Statlog German Credit, protected = sex)**

| Condition | AUC | DIR |
|---|---|---|
| with_protected | 0.777 | 0.844 |
| drop_protected | 0.777 | 0.920 |
| drop_proxies | 0.778 | 0.928 |
| **gov_engine** | **0.777** | **0.997** |

**E3 — Latency / overhead:** governance path adds **7.5%** per-request latency
(sub-millisecond absolute).

**E4 — Sensitivity:** across proxy-correlation strength (0.4–2.0) and base-rate
gap (0.15–0.45), `gov_engine` holds DIR ≈ 1.0 and preserves AUC.

**E5 — Multi-metric:** restoring DIR to 1.0 *increases* the equalized-odds gap
(ΔTPR 0.21 → 0.59) — an empirical instance of the fairness impossibility
result, motivating multi-metric monitoring.

## Reproduce

```bash
pip install -r requirements.txt
./run_all.sh            # runs E1–E5, regenerates results/{figures,tables}
```

Or run any notebook individually in Jupyter. The random seeds are fixed, so
results are deterministic.

**Environment used:** Python 3.12, scikit-learn 1.8, NumPy 2.4, pandas 3.0,
Matplotlib 3.11, seaborn 0.13. (The pinned lower bounds in `requirements.txt`
also reproduce the qualitative findings.)

## Data

- **German Credit (E2):** the public Statlog German Credit dataset (1,000
  applicants, 20 attributes). Protected attribute = applicant sex; target =
  credit default.
- **Synthetic (E1, E3–E5):** generated in-notebook; no real personal data are
  processed — a deliberate choice for a framework that critiques non-compliant
  data collection.

---

## Note on the fairness engine

Group-wise threshold calibration uses the protected attribute at decision time.
In some jurisdictions (e.g., under U.S. ECOA disparate-treatment doctrine) this
may be impermissible even when it improves parity. The framework treats legal
admissibility as a precondition; where the attribute may not be used, only
attribute-blind operators are admissible, and the framework's role is to
*surface* the resulting trade-offs for documented human judgment.
